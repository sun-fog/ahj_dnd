# Trello DnD


![Build](https://github.com/sun-fog/ahj_dnd/actions/workflows/deploy.yml/badge.svg)

[GitHub Pages](https://sun-fog.github.io/ahj_dnd/)

Доска задач в стиле Trello с drag-and-drop карточек.

## Возможности
- 3 фиксированные колонки
- Добавление карточек
- Удаление карточек (крестик при наведении)
- Перемещение карточек между колонками и внутри них (HTML5 DnD)
- Сохранение состояния в LocalStorage

## Запуск

```bash
yarn install
yarn start
```

## Сборка

```bash
yarn build
```
